DEPLOYMENT
- Upload the entire folder including index.html, hsk3-lesson1-questions.js,
  hsk3-lesson1-images/ and quiz-images/ to your static web project.
- If you have a Vercel/Git codebase, MERGE updates and deploy via your existing
  project setup. Avoid overwriting backend files or discarding newer work.
- This package does not automatically update your live hosting site.

IMPORTANT LIMITATIONS
- Static JavaScript data import, not a server-side database import.
- Progress/completion and teacher/student demo data use browser localStorage:
  not secure, cross-device synced, or a genuine teacher/student account system.
- The sample questions and teacher reports are prototypes. Teacher review
  of HSK 3 educational content is recommended before public launch.
