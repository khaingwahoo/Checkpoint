# Cambridge Stage 9 English, Unit 1

Open **Lower Secondary → Stage 9 → English → Unit 1 Going underground**.

- Sections 1.1–1.6 each contain 20 Easy, 15 Medium and 15 Difficult questions.
- Checkpoint Skills Practice contains 20 Medium and 30 Difficult questions.
- Learner’s Book references appear in answer feedback for the six subtopics.

The quiz data comes from `TEQ_Year9_English_Unit1_350.xlsx`.

This release gives one point per correct answer across quizzes and removes IGCSE from navigation.
Existing science point totals use one point per recorded correct answer.

For a deployment already using the Stage 9 English Unit 1 package, merge the
changes in `index.html` and replace `stage9-english-unit1-questions.js` in the
static web root. For a local preview, extract the full ZIP and open `index.html`.

After deployment, open an English subtopic, verify its three question counts
and answer a question to check the feedback. Confirm that Checkpoint Skills
Practice still opens with its reading passage.
